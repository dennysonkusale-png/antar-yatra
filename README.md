# Antar Yatra — Meditation, Ashtanga Yoga, Japa & Tap

A single-file, self-contained web page: a calm multilingual guide for devotees, yogis and seekers.

## Live site
https://dennysonkusale-png.github.io/antar-yatra/

## What's inside
- Foundations — dhyana (meditation), japa (mantra) and tap (discipline)
- **Ashtanga Yoga — the eight limbs**: yama, niyama, asana, pranayama, pratyahara, dharana, dhyana, samadhi
- How to meditate, step by step, and what happens with practice over time
- Postures & silhouettes — lotus, easy pose, chair, vajrasana, shavasana, walking
- A library of 12 techniques, each with method, duration, benefits and cautions
- Japa & tap with a working 108-bead digital counter
- A guided session player with a breathing guide and optional chime
- FAQ and a Sanskrit glossary
- Four languages: English, Hindi, Marathi and Sanskrit (switch in the header)
- Dark and light themes

## Notes
- One file, no build step — open `index.html` in any browser.
- The English page is baked into the HTML, so it renders even with JavaScript disabled; JS only powers the language switcher and the interactive tools.
- Fonts load from Google Fonts, with system fallbacks.
